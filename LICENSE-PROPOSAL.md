# Proposed release license

Proposed license for project-owned code, documentation, and the synthetic
assembly fixture: [MIT](https://spdx.org/licenses/MIT.html). This review
snapshot carries a proposal. Adopting MIT requires confirmation of the
copyright holder and authority to release the imported research code.
The approved release should carry the corresponding copyright notice and
license text. See [Third-party notices](THIRD-PARTY.md) for separate inputs.

The authorship of a Git commit alone does not establish those permissions.
